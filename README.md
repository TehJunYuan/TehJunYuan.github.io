# Teh Jun Yuan — Portfolio

A responsive portfolio for my work in ERP systems, business automation, AI/OCR processing, and web and mobile development.

**Website:** https://tehjunyuan.github.io/

## Run locally

No installation or build step is needed. Serve this directory:

```sh
python3 -m http.server 8080
```

Open http://localhost:8080.

## Update content

- `index.html`: portfolio content, experience, projects, and contact links.
- `css/style.css`: responsive layout, colors, and typography.
- `js/script.js`: mobile navigation and accessible project screenshot galleries.
- `assets/Teh-Jun-Yuan-Resume.pdf`: downloadable resume.
- `images/`: existing project screenshots and certificates.

Content is based on the supplied 2026 resume. Academic project descriptions and source links are retained from the previous portfolio. The ERP graphic is explicitly an architecture illustration rather than a production screenshot. Contact uses direct email and WhatsApp links; no external form service is required.

## GitHub Pages

This repository is designed for GitHub Pages to serve directly from the repository root. For branch-based deployment, select `main` and `/ (root)` under **Settings → Pages**. Changes pushed to the configured publishing branch will appear after GitHub completes deployment.

Google Fonts enhances the typography when available; local sans-serif fallbacks work without it.
